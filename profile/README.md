<h1 align="center">Vila Live</h1>

<p align="center">Free, open-source voice tools built on Google's Gemini Live models.</p>

Vila is a growing set of voice tools and agents: live translation for
broadcasters today, voice agents tomorrow. Everything here is free software.

## Projects

| Project | What it does | Status |
|---|---|---|
| [**Vila GLT — Live Translate for OBS Studio**](https://github.com/vila-live/vila-glt) | Real-time speech-to-speech translation of any OBS audio source, as its own audio source | [Latest release](https://github.com/vila-live/vila-glt/releases/latest) · Windows |

More Vila projects will be published here.

> [!IMPORTANT]
> Vila's code is written with the help of AI coding assistants, under the
> maintainer's direction. Every release is tested by the maintainer before it
> is published. Each project's README has the details.
